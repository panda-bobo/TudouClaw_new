## Hard Rules — Apply To All Plans

### Rule 1: Vertical-slice integrity (no UI without API, no API without UI)

User feedback after v1.0 plan review: "之前的错: 有 UI 没 API,无法操作"。

Every task that touches a user-facing feature MUST deliver:

```
1. Backend API implementation
2. Backend smoke test (curl returns 200)
3. Frontend UI calling that API
4. End-to-end browser verification
5. Commit
```

Pure-backend tasks (Track A/C/D) verify via `pytest`. Pure-frontend tasks (Track B) verify via browser click sequences AND the API they call must already exist (Phase 0 stubs or pre-existing).

### Rule 2: Existing-functionality untouched

```
不动 (Forbidden to modify):
  ❌ app/agent.py methods (only ADD 5 optional fields)
  ❌ app/hub/_core.py methods (only ADD 1 reply hook)
  ❌ app/llm.py
  ❌ app/skills/prompt_enhancer.py
  ❌ app/api/routers/agents.py routes (only ADD /expert/* sub-routes)
  ❌ Voice mode code
  ❌ Main requirements.txt (new deps go to requirements-expert.txt)
  ❌ SQL schema (new fields ride in agents.data JSON blob)

只动 (Allowed):
  ✓ NEW: app/domain_expert/
  ✓ NEW: app/data/specialty_templates/legal.yaml
  ✓ NEW: ~/.tudou_claw/expert/
  ✓ NEW: docs/superpowers/{specs,plans}/
  ✓ ADD agent dataclass 5 optional fields
  ✓ ADD reply pipeline if-branch (空 specialty 透明跳过)
  ✓ portal_bundle.js: ADD `_aws_*` / `_expert_*` prefixed functions
```

### Rule 3: Feature flag fallback

`TUDOU_EXPERT_DISABLED=1` env var → entire cultivation module skips initialization. Behavior reverts 100% to current. CI test: run with this flag, all existing tests pass.

### Rule 4: Each task ends with a commit

No accumulating uncommitted changes. Each task is one logical unit, one commit. Easy rollback.

### Rule 5: Self-review before next task

After completing a task, run a 30-second mental check:
- ☑ All 5 vertical-slice deliverables present?
- ☑ pytest / smoke test passing locally?
- ☑ TUDOU_EXPERT_DISABLED=1 still preserves existing functionality?
- ☑ Any cross-track collision? (e.g. did I import a Track B fn from Track A?)

If any ☐, fix before commit.
